# Sentinel-1 SAR crop type mapping, eastern Uttar Pradesh (Rabi 2021-22)

Work in progress. Author: Vaibhav Nagare.

The aim is a crop type map of Wheat, Mustard/Lentil and Sugarcane from Sentinel-1 C-band backscatter (VV and VH, ascending and descending orbits), checked on fields and spatial blocks that were not used for training. Sentinel-2 is used only as a comparison.

## Data
- Labels: AgriFieldNet field survey (Radiant Earth Foundation and IDinsight 2022, CC-BY-4.0, DOI 10.34911/rdnt.wu92p1). The ground survey was done in May 2022, after the Rabi harvest, so the crop of the season is recorded afterwards.
- Study block: six 0.5 degree cells in eastern Uttar Pradesh, 454 label chips, 2,522 fields. Over the whole AgriFieldNet training set the median field is 23 pixels (10 m) and 42% of fields are under 20 pixels.
- Sentinel-1 GRD from Google Earth Engine, 12-day composites from 1 Oct 2021 to 28 May 2022 (20 windows), features VV, VH and VH minus VV in dB. A 5 x 5 multi-temporal speckle filter (Quegan-Yu) is used for the pixel-level map model only.
- Train and test fields are separated by whole fields and by whole 0.1 degree blocks.

## Results so far
Independent test set, 3 classes (Wheat, Mustard+Lentil, Sugarcane), 412 test fields, Random Forest trained on all training fields. Intervals are 95% field-level bootstrap.

| Model | Level | Macro-F1 | AUC | Overall accuracy (always-wheat baseline) |
|---|---|---|---|---|
| Sentinel-1, ascending + descending | field | 0.560 [0.496, 0.625] | 0.837 [0.800, 0.870] | 0.701 (0.653) |
| Sentinel-1, ascending only | field | 0.536 [0.471, 0.597] | 0.798 [0.760, 0.832] | 0.667 (0.653) |
| Sentinel-1 + Sentinel-2 | field | 0.609 [0.545, 0.668] | 0.882 [0.850, 0.910] | 0.743 (0.653) |
| Sentinel-1 + Google satellite embeddings | field | 0.597 [0.529, 0.657] | 0.860 [0.827, 0.889] | 0.714 (0.653) |
| Sentinel-1 map model | pixel | 0.517 [0.474, 0.558] | 0.783 [0.750, 0.816] | 0.647 (0.675) |

Per class (field level, Sentinel-1 two orbits): Wheat recall 0.81, Mustard/Lentil 0.55, Sugarcane 0.30. The full tables and confusion matrices are in `results/test_summary.md`.

## Limitations
- Accuracy is modest. Mustard/Lentil fields are often labelled Wheat and most Sugarcane fields are missed. Pixel-level overall accuracy is below the always-wheat baseline, so macro-F1, balanced accuracy and AUC are the metrics to read.
- Cross-validation on training blocks gave higher scores (field macro-F1 0.645) than the test set. The test set has 12 spatial blocks and 33 Sugarcane fields.
- Small fields: Sentinel-1 pixels mix neighbouring fields. Accuracy rises with field size.
- The labels come from a survey after harvest and are not a probability sample, so mapped areas are not unbiased area estimates.
- Lentil was merged with Mustard because there are too few Lentil fields.

## Repository layout
```
src/        shared modules (study, features, env_fix) and pipeline scripts p0_ to p6_, runbooks run_*.py
tests/      self-tests on synthetic data and a fake Earth Engine; run: python tests/run_all.py
results/    small committed outputs: frozen configuration, test metrics, confusion matrices
docs/       GitHub Pages site (not built yet)
reports/    codebook and project documents
data/       not committed (labels, features, dense chips); regenerated by the scripts
notes/      not committed
```

## Setup (Windows, VS Code terminal, repository root)
```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python tests/run_all.py
```
Scripts are run from the repository root, for example `python src/p3_sweep.py ...`. Earth Engine needs `earthengine authenticate` with the account that owns the Cloud project.
