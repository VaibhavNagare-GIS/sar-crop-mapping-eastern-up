# Sentinel-1 SAR crop type mapping, eastern Uttar Pradesh (Rabi 2021-22)

Author: Vaibhav Nagare. Status: work in progress (results, map and website are added as the phases finish).

Goal: map Wheat, Mustard/Lentil and Sugarcane from Sentinel-1 C-band SAR time series (ascending and descending orbits), validated on fields and spatial blocks that the model never saw. Labels: AgriFieldNet (Radiant Earth Foundation and IDinsight 2022, CC-BY-4.0).

## Layout
```
src/        shared modules (study, features, env_fix) and pipeline scripts p0_ to p5_, runbooks run_*.py
tests/      self-tests on synthetic data and a fake Earth Engine; run: python tests/run_all.py
results/    small committed outputs: metrics, confusion matrices, figures
docs/       GitHub Pages website
reports/    workflow record, study-area package, paper matrix, AI-use declaration, phase notes
data/       NOT committed (labels, features); regenerated by the scripts
notes/      NOT committed (private working notes)
```

## Quick start (Windows, VS Code terminal, from the repository root)
```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python tests/run_all.py
```
All scripts are run from the repository root, for example `python src/p3_sweep.py ...`. Data go to `data/`. Earth Engine needs `earthengine authenticate` with the account that owns the Cloud project.
